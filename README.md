# Lo que cuento

Un cuaderno privado para contar todo: una página por día, con renglones, el clima de tu ánimo y etiquetas.

Todo vive en un solo archivo, `index.html`, sin dependencias ni paso de compilación.

```bash
python3 -m http.server 8000   # o abre index.html directo en el navegador
```

## Qué hace

- **La hoja**: título y texto sobre papel de renglones con margen. Se guarda sola mientras escribes.
- **El clima del día**: despejado, templado, nublado, lluvia o tormenta. Colorea la gota de tinta del calendario.
- **Etiquetas**: escribe `#familia`, `#trabajo` o lo que quieras dentro del texto; aparecen en el índice para filtrar.
- **Índice**: calendario del mes (toca un día para abrir o escribir esa página), páginas, días seguidos y palabras, búsqueda.
- **Ideas para empezar** cuando la página está en blanco.
- Modo claro y oscuro según tu sistema. En el celular, el índice y la hoja se alternan.

## Dónde se guarda

- **Abierto desde Claude** (artifact): en tu cuenta, en tu espacio privado. Nadie más puede leerlo, tampoco
  alguien con quien compartas la página: cada persona ve solo su propio cuaderno.
- **Abierto como sitio normal**: en el almacenamiento de ese navegador. Si borras los datos del sitio, se
  borran las páginas.
